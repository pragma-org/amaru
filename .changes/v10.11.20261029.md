## [v10.11.20261029](https://github.com/pragma-org/amaru/releases/tag/v10.11.20261029)

 ### Added

- **amaru**: `amaru pool cert inspect` prints the pool ID, sequence number, KES period, and KES verification key from an operational certificate.
- **amaru**: `amaru pool kes period` shows the current KES period and how many periods remain before key rotation is required.
- **amaru**: `amaru pool id inspect` derives the pool ID from a cold verification key file.
- **amaru**: `amaru pool vrf create --signing-key PATH --verification-key PATH` generates raw binary VRF keys for block production without replacing existing files. The node automatically accepts raw signing keys and cardano-cli JSON text envelopes.
- **amaru**: `amaru pool vrf inspect --verification-key PATH` prints the VRF key hash from a raw verification key generated by `amaru pool vrf create`.

### Changed

- **amaru**: KES key pairs are generated with `amaru pool kes create`. The former `amaru keys kes create` command is removed.
- **amaru**: logs, errors and `amaru dev chain dump` show stake pool IDs in bech32 (`pool1…`) rather than hex.
- **amaru-uplc**: release builds now explicitly use the faster LGPL-licensed Malachite backend for integer arithmetic, while regular builds continue to use Dashu. See `THIRD_PARTY_NOTICES.md` for the applicable notices.
- **amaru-uplc**: rework uplc turbo benchmarks and uplc conformance to emit JSON results aggregated into a report. Both datasets have also been cleaned up and reorganised more logically.
- **amaru-uplc**: turn runtime arguments into a chain of pointers, rather than a vec.

### Fixed

- **amaru**: Linux (musl) release binaries no longer segfault at startup or shutdown. They are linked with a pinned zig 0.15.2, because zig 0.17 lets libc allocations bypass jemalloc.
- **amaru-node**: startup reliably reports listener bind errors, including an occupied port, when the network manager exits immediately after the failed bind.
- **amaru-ledger**: transactions whose Plutus redeemers declare execution units summing past 2^64 are rejected, instead of wrapping the totals.
- **amaru-ledger**: reject transactions that delegate stake or votes from an unregistered stake credential, or that update an unregistered DRep.
- **amaru-ledger**: transactions without redeemers are rejected when a collateral input lacks its owner's signature.
- **amaru-ledger**: transactions spending a Byron redemption-address input or naming one as collateral are rejected for a missing witness.
- **amaru-ledger**: treasury donations from transactions that fail phase-two script validation are no longer credited to the treasury.
- **amaru-uplc**: prevent byte-string builtin results from retaining global-allocator buffers after an evaluation arena is reset, reducing memory growth across repeated script evaluations.
- **amaru-uplc**: optimize out unnecessary allocations of empty vectors.
- **amaru-kernel**: fixed the decoding of port, constitution, `invalid_transactions` and `pool_metadata` content hash.
- **amaru-uplc**: move machine version checks to parsing-time instead of execution-time to match Haskell's behavior.
- **amaru-uplc**: fix 'is_constr_case_available' check wrongly assuming min protocol version 10.
- **amaru-uplc**: refresh cost models and associate them to _semantics_ instead of _plutus version_.
- **amaru-uplc**: lazily discharge UPLC machine final value, avoiding extra (unpaid) runtime cost when not needed.
- **amaru-ledger**: a transaction whose fee or outputs add up to 2^63 lovelace or more is rejected as not value-conserved, instead of crashing the node.
- **amaru-kernel**: implement the same faulty logic as the Haskell node for decoding invalid transactions in Conway.
- **amaru-kernel**: check the uniqueness of the Plutus scripts during decoding.
